# NimbusIQ – Atomity Frontend Challenge

A modern, responsive cloud monitoring dashboard built as part of the Atomity Frontend Challenge.

## Live Demo

🔗 https://atomity-frontend-three.vercel.app

## GitHub Repository

🔗 https://github.com/Ankit8568/atomity-frontend

---

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- TanStack React Query
- Axios

---

## Features

- Responsive dashboard UI
- Smooth animations with Framer Motion
- Live API data using React Query
- Component-based architecture
- TypeScript for type safety
- Accessible and semantic HTML
- Production-ready layout

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Ankit8568/atomity-frontend.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
